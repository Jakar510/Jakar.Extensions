# Jakar.Extensions.Maui.Syncfusion

[Syncfusion .NET MAUI](https://www.syncfusion.com/maui-controls) helpers for Jakar MAUI apps.

**Status: not released.** The project is a scaffold with no public API yet, and it isn't part of the solution build. It still targets .NET 9 (`net9.0-*`), unlike the rest of the repository.

When it ships, it follows the repository's versioning scheme, `<.NET major>.<library major>.<library minor>`. See the [repository README](https://github.com/Jakar510/Jakar.Extensions#versioning).
