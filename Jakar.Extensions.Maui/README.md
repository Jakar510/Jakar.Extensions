# Jakar.Extensions.Maui

.NET MAUI extensions built on [Jakar.Extensions](https://www.nuget.org/packages/Jakar.Extensions/) and the .NET MAUI Community Toolkit.

**Status: not released.** The project is a scaffold with no public API yet (only the template's per-platform stubs), and it isn't part of the solution build. The `6.0.0.x-beta` packages on nuget.org are from an earlier version of the project.

When it ships, it follows the repository's versioning scheme, `<.NET major>.<library major>.<library minor>`, starting at 10.1.0 for .NET 10. See the [repository README](https://github.com/Jakar510/Jakar.Extensions#versioning).
